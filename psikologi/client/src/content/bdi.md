### Petunjuk Pengisian

Untuk setiap kelompok pernyataan, pilih **satu** kalimat yang paling menggambarkan
perasaan Anda selama **dua minggu terakhir**.

1. 
    - 0. Saya tidak merasa sedih.
    - 1. Saya merasa sedih lebih sering daripada biasanya.
    - 2. Saya merasa sedih sepanjang waktu dan tidak bisa lepas darinya.
    - 3. Saya begitu sedih atau tidak bahagia hingga tak tahan lagi.
2. 
    - 0. Saya tidak terlalu putus asa melihat masa depan.
    - 1. Saya merasa lebih putus asa tentang masa depan daripada biasanya.
    - 2. Saya merasa tidak ada yang bisa diharapkan dari masa depan saya.
    - 3. Saya merasa masa depan saya tanpa harapan dan segalanya hanya akan bertambah buruk.
3. 
    - 0. Saya tidak merasa sebagai orang yang gagal.
    - 1. Saya merasa lebih sering gagal daripada orang pada umumnya.
    - 2. Bila mengenang hidup saya, saya hanya melihat banyak kegagalan.
    - 3. Saya merasa benar-benar gagal sebagai pribadi.
4. 
    - 0. Saya memperoleh kepuasan seperti biasanya dari hal-hal yang saya lakukan.
    - 1. Saya tidak lagi menikmati hal-hal seperti dulu.
    - 2. Saya tidak memperoleh kepuasan nyata dari apa pun lagi.
    - 3. Saya bosan atau muak terhadap segala hal.
5. 
    - 0. Saya tidak merasa terlalu bersalah.
    - 1. Saya merasa bersalah dalam banyak hal yang saya lakukan.
    - 2. Saya merasa bersalah hampir sepanjang waktu.
    - 3. Saya merasa bersalah sepanjang waktu.
6. 
    - 0. Saya tidak merasa sedang dihukum.
    - 1. Saya merasa bisa saja saya dihukum.
    - 2. Saya mengharap akan dihukum.
    - 3. Saya merasa sedang dihukum karenanya.
7. 
    - 0. Saya tidak merasa kecewa pada diri sendiri.
    - 1. Saya kecewa pada diri sendiri.
    - 2. Saya muak pada diri sendiri.
    - 3. Saya membenci diri sendiri.
8. 
    - 0. Saya tidak merasa lebih buruk daripada orang lain.
    - 1. Saya mengkritik kelemahan atau kesalahan saya sendiri.
    - 2. Saya menyalahkan diri sendiri sepanjang waktu atas kegagalan saya.
    - 3. Saya menyalahkan diri sendiri atas semua hal buruk yang terjadi.
9. 
    - 0. Saya tidak memiliki pikiran untuk bunuh diri.
    - 1. Ada pikiran untuk bunuh diri, tetapi saya tidak akan melakukannya.
    - 2. Saya ingin bunuh diri.
    - 3. Saya akan bunuh diri bila ada kesempatan.
10. 
    - 0. Saya tidak menangis lebih sering daripada biasanya.
    - 1. Saya menangis lebih sering daripada dulu.
    - 2. Saya menangis karena hal sepele.
    - 3. Saya ingin menangis tetapi tidak mampu.
11. 
    - 0. Saya tidak merasa lebih gelisah daripada biasanya.
    - 1. Saya merasa sedikit lebih gelisah daripada biasanya.
    - 2. Saya sangat gelisah atau resah.
    - 3. Saya begitu gelisah hingga perlu terus bergerak atau berjalan.
12. 
    - 0. Saya tidak kehilangan minat pada orang lain.
    - 1. Saya kurang tertarik pada orang lain daripada dulu.
    - 2. Minat saya terhadap orang lain sangat berkurang.
    - 3. Saya kehilangan semua minat pada orang lain.
13. 
    - 0. Saya mengambil keputusan sebaik biasanya.
    - 1. Saya lebih sering menunda mengambil keputusan daripada dulu.
    - 2. Saya kesulitan mengambil keputusan dibandingkan dulu.
    - 3. Saya tidak bisa mengambil keputusan sama sekali.
14. 
    - 0. Saya tidak merasa lebih buruk rupanya daripada sebelumnya.
    - 1. Saya khawatir terlihat tua atau tidak menarik.
    - 2. Saya merasa ada perubahan permanen dalam penampilan sehingga tidak menarik.
    - 3. Saya yakin saya terlihat jelek.
15. 
    - 0. Saya dapat bekerja sebaik biasanya.
    - 1. Diperlukan usaha ekstra untuk memulai sesuatu.
    - 2. Saya harus memaksa diri untuk melakukan apa pun.
    - 3. Saya tidak bisa bekerja sama sekali.
16. 
    - 0. Saya tidur sebaik biasanya.
    - 1. Saya tidak tidur sebaik dulu.
    - 2. Saya bangun 1-2 jam lebih awal dan sulit tidur lagi.
    - 3. Saya bangun beberapa jam lebih awal dan tidak bisa tidur kembali.
17. 
    - 0. Saya tidak merasa lebih lelah daripada biasanya.
    - 1. Saya lebih mudah lelah daripada biasanya.
    - 2. Hampir segala hal membuat saya lelah.
    - 3. Saya terlalu lelah untuk melakukan apa pun.
18. 
    - 0. Nafsu makan saya tidak lebih buruk dari biasanya.
    - 1. Nafsu makan saya sedikit lebih buruk daripada biasanya.
    - 2. Nafsu makan saya jauh lebih buruk daripada biasanya.
    - 3. Saya tidak punya nafsu makan sama sekali.
19. 
    - 0. Berat badan saya tidak banyak berubah akhir-akhir ini.
    - 1. Berat badan saya turun/naik beberapa kilogram.
    - 2. Berat badan saya berubah cukup banyak.
    - 3. Berat badan saya berubah sangat drastis.
20. 
    - 0. Saya tidak terlalu cemas tentang kesehatan saya daripada biasanya.
    - 1. Saya khawatir tentang sakit, nyeri, atau masalah pencernaan.
    - 2. Saya sangat sibuk memikirkan keluhan kesehatan.
    - 3. Saya begitu mengkhawatirkan kesehatan hingga memikirkan hal lain terganggu.
21. 
    - 0. Saya tidak memperhatikan perubahan gairah seks saya.
    - 1. Gairah seks saya sedikit berkurang daripada biasanya.
    - 2. Gairah seks saya sangat berkurang.
    - 3. Saya kehilangan minat pada seks sepenuhnya.
