## Project web namajemen UKM English Club (EC)
Project ini adalah kebutuhan dari mata kuliah atas (semester 5) pada saat sy semester 3. Mata kuliah pemograman Web 1. Teknologi yang aku pakai adalah php native dengan framework tailwind css dan mysql sebagai database. Untuk keterangan webnya disini ada landing page terkait detail UKM EC.

Disana juga ada LMS untuk anggota untuk bisa mengakses materi dan absen dengan token yang dibuat oleh admin divisi pendidikan 
untuk admin divisi SDM bisa melihat hasil kehadiran anggota dan pengurus yg akan bisa export pdf/excel

secara garis besar untuk project ini ada lms, sistem kehadiran anggota dan pengurus dan landing page untuk informasi UKM EC

## Project LMS Divisi Software 
Project ini adalah project inisiatif sy untuk kebutuhan pembelajaran untuk anggota 25 oxigen sebagai media belajar mereka. Untuk teknolog yang aku pakai adalah react dan tailwind, web ini bersifat statis yg artinya tidak menggunakan database. Tapi menggunakan react-markdown jadi untuk pembuatan materinya ini menggunkana format markdown yang nanti akan dibca oleh web appnya dan menampilkan di borwser dengan bagus 

## Power Point Custom
Project ini adalah project inisiatif sy untuk kebutuhan pembelajaran dalam mengajar. Berawal dari keresahan sy dalam membuat materi sebelum pelatihan yang harus mencari dan mendesain, maka dari itu saya membuat web app yg dimana saya tinggal fokus menjadi materi dan menulis di markdown.
